# 20 - Teacher System & Educator Tools

The Teacher Portal (`src/components/dashboards/TeacherDashboard.tsx`) provides tools to assist educators:

1. **AI Lesson Plan Generator**:
   - Creates CAPS/IEB aligned lesson plans complete with learning objectives, starter activities, core instruction, guided practice, and assessment tasks.
2. **Automated Rubric Auto-Grader**:
   - Evaluates student essay submissions against customized scoring rubrics, generating constructive feedback and score breakdowns.
3. **Class Performance Analytics**:
   - Visualizes class-wide mastery rates across specific curriculum topics (e.g. Euclidean Geometry, Differential Calculus, Organic Chemistry).
4. **Homework & Quiz Creator**:
   - Generates printable or digital quiz assignments with answer keys and step-by-step marking memorandums.
