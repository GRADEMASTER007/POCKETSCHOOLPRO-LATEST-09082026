# 21 - Parent System & Guardian Overview

The Parent Portal (`src/components/dashboards/ParentDashboard.tsx`) bridges the gap between home and school:

1. **Real-time Academic Activity Feed**:
   - Displays topics studied, quizzes completed, Vision AI homework scans conducted, and total time spent in study sessions.
2. **Weekly Mastery Reports**:
   - Generates summary reports detailing strengths, areas requiring revision, and upcoming exam readiness metrics.
3. **Study Streak & Goal Verification**:
   - Allows parents to inspect daily study goals and verify completed assignments.
4. **Direct Teacher Communication**:
   - Integrated messaging interface to review educator feedback and notes.
