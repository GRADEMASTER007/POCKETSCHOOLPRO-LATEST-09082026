## 🌟 Key Features & 4K Experience Highlights

### 1. 4K Space Science Landing & Gold Branding
- **Gold Luxury Visual Identity**: Shimmering Gold emblem logo, metallic gradient typography (`Pocket School Pro Gold Edition`), and dark cosmic space universe canvas.
- **Google Ecosystem Badging**: Official Google Cloud, Vertex AI, Google Vision AI, and Gemini 1.5 Pro / Flash integration.

### 2. Feynman AI Whiteboard & D3 Function Plotter
- **KaTeX Mathematical Notation**: High-performance LaTeX formula rendering in step-by-step containers.
- **D3.js Coordinate Plotter**: Interactive SVG function graphing with tangent derivative sliders, definite integral region shading, and real-time hover coordinate readouts.

### 3. Google Vision AI Step-by-Step Homework Doctor
- **Interactive Scanning & OCR**: Parameter extraction for handwritten calculus, physics momentum, and chemistry structural equations.
- **Step-by-Step Explanations**: Generates clear explanations with formula rendering and live speech narration.

### 4. Language Master & Writing Suite
- **Language Hub**: Real-time translation, grammar analysis, and lessons for 40+ African languages.
- **Topic Master AI**: On-demand generator for study decks, quizzes, and flashcards.
- **Writing Assistant**: Drafting help for essays, letters, and assignments.
- **CV Builder**: Intelligent career coach for building professional CVs and PDFs.
- **AI Notes Master**: Intelligent homework assistant for capturing and summarizing photos of notes.

### 5. Inclusive Education & Sign Language Center
- **Accessibility Hub**: Unified center for students with visual, auditory, or cognitive disabilities. Includes High Contrast Mode, Dyslexic-Friendly fonts (Lexend), Reduced Motion, and Screen Reader optimizations.
- **Sign Language Center**: Visual library for American and South African Sign Language (ASL/SASL) with interactive hand-gesture cards.

### 6. Tiered Subscription & Financial Unit Economics (53%+ Profit)
- **Individual Student Passes**:
  - **R49 Basic Starter**: 150k Tokens/mo, 30 AI Queries/day, 10 Homework Scans/day.
  - **R69 Student Plus**: 350k Tokens/mo, 75 AI Queries/day, 25 Homework Scans/day, CAPS/IEB Exam Engine.
  - **R99 Standard Pass**: 750k Tokens/mo, 150 AI Queries/day, 50 Homework Scans/day, Feynman Whiteboard Lab.
  - **R199 Gold VIP Pass**: 2.5M Tokens/mo, 300 AI Queries/day, 100 Homework Scans/day, Multilingual Spoken AI Tutor, **3-Day Free Trial**.
- **Institutional School Base Passes**:
  - **R499 School Base 25**: Up to 25 Learners (10M Pooled Tokens, ~R19.96/seat).
  - **R1,899 School Base 100**: Up to 100 Learners (35M Pooled Tokens, ~R18.99/seat).
  - **R4,999 School Base 300**: Up to 300 Learners (90M Pooled Tokens, ~R16.66/seat).
  - **R14,999 School Base 1000**: Up to 1,000 Learners (250M Pooled Tokens, ~R14.99/seat).

- **Installable on All Devices**: Complete PWA configuration with Web App Manifest (`manifest.json`), service worker (`firebase-messaging-sw.js`), and desktop/mobile installation guide (`/pwa-install`).

## 🛠️ Quick Start & Development

### 1. Prerequisites
- **Node.js**: `v18.x` or `v20.x`
- **npm**: `v9.x` or higher

### 2. Installation
```bash
npm install
```

### 3. Environment Setup
Copy `.env.example` to `.env` and supply your secrets:
```bash
cp .env.example .env
```
Key variables: `GEMINI_API_KEY`, `APP_URL`, `VITE_YOCO_PUBLIC_KEY`, `YOCO_SECRET_KEY`, `FIREBASE_*`.

### 4. Start Development Server
```bash
npm run dev
```

### 5. Build & Production Launch
```bash
npm run build
npm run start
```
*Listens on Port `3000` and host `0.0.0.0`.*
